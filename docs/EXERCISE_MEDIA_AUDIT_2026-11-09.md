## Como verificar

1. Executar `npm ci && npm run build` e `npm run lint`.
2. Abrir catálogo, detalhes, treinos e programas e conferir cada nova imagem, incluindo as duas fases.
3. Identificar fotos com erro de carregamento ou variante incompatível e remover sua correspondência.
4. Para cobrir os demais 112, obter fotos originais corretamente licenciadas e adequadas a cada movimento.
