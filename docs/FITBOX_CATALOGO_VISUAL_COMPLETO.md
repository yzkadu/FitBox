# Catálogo visual completo do FitBox — 327 exercícios

Os 89 quadros de execução enviados pelo usuário foram separados em imagens WEBP. Os outros 238 exercícios usam referências pré-existentes. A existência de um mapeamento não equivale a validação técnica das imagens. Este documento especifica o modelo visual único para padronizar o aplicativo.

## Modelo visual unificado

Cada exercício deve ter imagem de execução sem texto impresso (o nome vem da interface), início/fim do movimento quando fizer sentido, proporção consistente, equipamento, instruções, fonte e indicação de revisão técnica. O mapa muscular é separado da execução. Evitar cortar pés, mãos ou equipamento nas miniaturas.
